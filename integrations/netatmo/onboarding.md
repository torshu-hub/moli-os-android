# Set up Netatmo Energy

In Android Management → Integrations → Netatmo, configure a personal application
and accept its experimental status. Register the exact redirect
`http://localhost/moli-netatmo`. Application secret and browser return belong only
in the private masked inputs, never chats, screenshots or reports.

Confirm reading consent; optionally enable official thermostat writes. Authorize
in the official browser, then paste the full return address into Moli. List the
homes returned by the account and explicitly connect the correct one. The driver
publishes the supported rooms/modules; use Moli labels for names and rooms.

Once connected, let the engine renew tokens. A temporary network/quota error or
an APK update does not by itself require authorization again. The page shows
saved authorization separately from actual recent collection and errors.

Writes appear only for a real supported capability and write consent. Choose an
explicit duration for a temporary setpoint, or resume the program. No physical
command is part of automated installation or tests. The owner confirms real
account compatibility and renewal persistence voluntarily after installation.
